# TODO

This file lists the resources that still need to be reversed, documented or converted. Items are ordered from easiest to hardest, as estimated from their structure and from the readers that already exist.

1. **Saved games need more samples.** The only saved game, `saves/000002 - Game1/`, is documented and converted, but every value in its `GLOBALVARS.res` is 0. The Xbox code and the PC code now give the bit order of `ValBoolean` and the size of `ValLocation`, but no PC file tests them. A save in which a known global boolean is true and a global location is set would confirm both for the PC build. `ReadGlobals` should then decode `ValLocation` into positions and facings instead of writing hexadecimal. The rule that decides which faction pairs `repute.fac` stores is also UNKNOWN.

2. **Two questions about supermodel node numbers remain.** The converter now records the animations that each model inherits from its supermodel chain, in shared animation files (see "Conversion of supermodel animations" in the README). How the tools chose the node numbers of a model with a supermodel, and why the count at 0x2C includes an extra 1, are still UNKNOWN. No loader of the shared files has been written, so the retargeting rule for translations has not been checked visually.

3. **More of the engine code can be read.** The PC code can be decrypted with Steamless and disassembled like the Xbox code. The routines traced so far are listed with their addresses in `README.md`. The cube face order and the float at 0x04 of the TPC header, the GUI field ALIGNMENT, the localized strings of ERF archives and the resource type names are settled. Fields that the code could still settle include the slots 28 to 48 of an SSF sound set, whose reader was not found; what the GUI fields FILLSTYLE, DIMENSION, INNEROFFSET, PULSING, DRAWSTYLE and FLIPSTYLE do; how the model maps a LIP value to a pose of the `talk` animation; the use of the TPC alpha mean; and the unknown fields of the mesh header, which the binary model loader and the renderer read.

Individual fields marked UNKNOWN in `README.md` are not listed here. Most of them are constant or never occur in the game files, so the files alone cannot settle them.
